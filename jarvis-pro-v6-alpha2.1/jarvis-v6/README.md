# Jarvis v6 — расширяемая локальная сборка для Windows

Jarvis v6 развивается отдельно: архивы v4 и v5 сохранены как резервные версии. Это alpha-сборка для поэтапного внедрения набора из 100 идей; новые функции добавляются и проверяются партиями, поэтому текущий архив пока не содержит все 100 функций. Для локального чата нужны Ollama и модель; внешние сервисы включаются только после локальной настройки пользователя.

## Один чат для всех навыков

Любой текстовый или голосовой запрос проходит через один чат, а ответы и результаты остаются в одной ленте. Кнопки слева — необязательные ярлыки: выбирать отдельный режим перед каждой командой не нужно. Напиши **«Покажи навыки»**, чтобы Джарвис вывел подсказки.

Примеры команд прямо в чате:

- «Найди в интернете …» или «Подробно изучи несколько сайтов про …»; короткие варианты: `/web запрос`, `/deep запрос`, `/google запрос`.
- «Добавь документ» — откроется диалог выбора файла; «Покажи документы» выводит индексированный список; «Управляй документами» открывает менеджер.
- «Запомни, что …», «Что ты помнишь?», «Управляй памятью».
- «Какие у меня сегодня события?», «Покажи состояние умного дома».
- «Напомни через 10 минут …», «Открой блокнот», «Будет ли дождь в Тбилиси?».
- «Покажи голограмму», «Переключи режим микрофона на push-to-talk», «Выключи микрофон».
- «Суммируй буфер обмена» или «Переведи текст из буфера» — буфер читается только после такой команды.
- «Сравни два документа» — выбери ровно два локальных файла.
- «Сохрани последний ответ» (DOCX/TXT) или «Сохрани последний ответ аудио» (WAV).
- «Включи локальную историю», «Найди в истории …», «Закрепи последний ответ», «Покажи закладки».

История переписки по умолчанию выключена и начинает сохраняться на этом ПК только после явной команды «Включи локальную историю». Закладки сохраняются только по явной команде. Удаление документов из индекса запрашивает подтверждение и никогда не удаляет исходный файл. Навыки, требующие окна выбора файла или настройки, тоже вызываются фразой в чате; их окна управления остаются дополнительными интерфейсами.

## Что входит

- Обновлённый тёмный интерфейс единого чата: быстрые команды, отдельный индикатор состояния и согласованные элементы управления.
- Экранный анимированный HUD и отображение уровня микрофона.
- Три переключаемых режима микрофона: фраза с «Джарвис», непрерывное прослушивание по кнопке и push-to-talk (зажать кнопку микрофона).
- Локальная Ollama-модель; доступные установленные модели можно выбирать в левой панели.
- Управляемая пользователем локальная память и индекс документов (TXT, MD, HTML, PDF, DOCX). Для сканированных PDF OCR не включён.
- Локальные напоминания и таймеры: например, «Напомни через 10 минут проверить духовку».
- Экранный HUD, часы, погода и веб-поиск.
- Google Calendar: чтение списка ближайших событий после локальной OAuth-настройки (OAuth scope только для чтения).
- Home Assistant: состояния устройств и управление только явно разрешёнными сущностями. Перед изменением состояния Jarvis просит голосовое подтверждение.
- Новое для v6: локальная история чатов с явным включением, закладки ответов, команды для работы с буфером обмена, сравнение двух документов и экспорт ответа в DOCX/TXT/WAV.
- Запуск приложений ограничен встроенным белым списком; произвольные команды оболочки не исполняются.

## Установка и запуск

1. Установи Python 3.10+ для Windows и Ollama. Убедись, что команда `ollama` доступна в PowerShell.
2. Скачай локальную модель и запусти Ollama:
   ```powershell
   ollama pull qwen2.5:7b
   ```
   В настройках интерфейса можно выбрать другую уже установленную модель.
3. Установи зависимости из папки проекта:
   ```powershell
   py -m pip install -r requirements.txt
   ```
4. Помести распакованную русскую модель Vosk в папку проекта так, чтобы путь был:
   `vosk-model-small-ru-0.22\am`, `...\conf`, `...\graph`.
5. Запусти GUI:
   ```powershell
   py .\jarvis_gui.py
   ```
   Или используй `run_gui.bat`.

`jarvis.py` — backend, `jarvis_gui.py` — GUI. Настройки модели и режима микрофона сохраняются в `jarvis_settings.json`.

## Голосовые режимы

Выбери режим в левой панели и нажми кнопку микрофона. В режиме по имени произноси «Джарвис, …». В кнопочном режиме микрофон остаётся включённым до повторного нажатия. В push-to-talk удерживай кнопку микрофона во время фразы и отпусти после команды. Распознавание Vosk выполняется локально.

## Память и документы

Память и индекс хранятся локально в файлах `jarvis_memory.sqlite3` и `jarvis_knowledge.sqlite3`. Добавляй документы через «Добавить документы», просматривай и удаляй их через «Управлять документами»; это удаляет только локальный индекс, не исходный файл. Память также можно просматривать и очищать в GUI. В архиве проекта пользовательские базы не поставляются. Поддерживаются TXT, MD, HTML, DOCX и PDF с текстовым слоем; поиск по документам лексический. Для сканированных PDF OCR не включён.

Напоминания сохраняются локально в `jarvis_reminders.sqlite3`. Например:
- «Напомни через 15 минут позвонить маме»
- «Поставь таймер на 5 минут»

## Google Calendar — настраивается пользователем локально

1. В Google Cloud Console включи Google Calendar API, создай OAuth client для Desktop app и скачай JSON.
2. Положи файл рядом с `jarvis.py` под именем `credentials.json`.
3. Нажми «Мой календарь» или спроси у Jarvis о событиях. При первом подключении откроется окно Google OAuth; токен останется локально в `calendar_token.json`.

Не отправляй `credentials.json` и `calendar_token.json` в чат и не добавляй их в архив/общий репозиторий. Эти файлы исключены из `.gitignore`.

## Home Assistant — настраивается пользователем локально

Создай в Home Assistant отдельный долгоживущий токен и заранее реши, какими entity_id разрешено управлять. В PowerShell **на своём компьютере** задай переменные и затем запусти программу из той же сессии:

```powershell
$env:JARVIS_HA_URL = "http://homeassistant.local:8123"
$env:JARVIS_HA_TOKEN = "ВСТАВЬ_ТОКЕН_ЛОКАЛЬНО_ЗДЕСЬ"
$env:JARVIS_HA_ALLOWED_ENTITIES = "light.kitchen,switch.office"
py .\jarvis_gui.py
```

В allowlist добавляй только точные entity_id, которым доверяешь. Без URL, токена и allowlist интеграция не управляет устройствами. На команду вроде «включи свет на кухне» Jarvis сначала попросит подтверждение; изменение произойдёт только после фразы «подтверждаю включить свет на кухне» и только если разрешённая сущность однозначно сопоставилась.

Токен не вставляй в исходники и не отправляй в чат. Переменные `$env:` действуют только в текущем окне PowerShell; после закрытия сессии задай их снова.

## Данные и конфиденциальность

- Настройки, память, документы, напоминания, избранные ответы и OAuth-токен хранятся локально в папке проекта.
- История чатов по умолчанию выключена; при включении она сохраняется в `jarvis_chat_history.sqlite3` и управляется из чата/окна истории.
- Пароль/токен Home Assistant не записывается в настройки Jarvis: он передаётся через переменную среды процесса.
- Текстовые запросы к Ollama обрабатываются локально. Google Calendar, Home Assistant, погода и веб-поиск используют сеть только при вызове соответствующей функции.
- Не включай `credentials.json`, `calendar_token.json`, базы `.sqlite3` и `jarvis_settings.json` в общие архивы.

## Сборка Windows-приложения

Запусти `build_exe.bat` для сборки папки `dist\Jarvis`. Для включения Vosk-модели положи `vosk-model-small-ru-0.22` в корень проекта до сборки. Пользовательские OAuth-файлы и секреты намеренно не включаются.

> HUD сейчас экранный; для физического проектора в будущем потребуется отдельное совместимое устройство.

Списки идей 1–100 и продолжение 101–125 сохранены в `IDEAS_50.md`, `IDEAS_51_100.md` и `IDEAS_101_125.md`. План этапов — `ROADMAP_100.md`.
