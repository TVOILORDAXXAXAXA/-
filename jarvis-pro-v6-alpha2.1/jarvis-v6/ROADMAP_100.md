# План внедрения 100 идей в Jarvis v6

## Принципы

- v4 и v5 не перезаписываются; работа ведётся в отдельной v6.
- Изменения выпускаются группами в проверяемых ZIP-архивах.
- Локальные данные остаются на этом ПК. Новая история чатов выключена по умолчанию.
- Захват экрана/буфера, запись аудио, отправка писем, управление домом и сетевой обмен выполняются только по явному запросу; опасные действия требуют отдельного подтверждения.
- Внешние интеграции остаются выключенными до локальной настройки пользователя.

## Стартовая партия v6

Реализованы первые локальные функции из списка 51–100:

- **#54** — работа с буфером обмена только по явной команде: краткое изложение, объяснение, перевод, форматирование; содержимое не пишется в журнал истории.
- **#68** — экспорт последнего ответа в WAV через локальный TTS.
- **#70** — сохранение последнего ответа в TXT/DOCX (пока без PDF/XLSX).
- **#71** — локальный поиск истории чатов; сохранение отключено по умолчанию и включается командой.
- **#72** — явное сохранение последнего ответа в локальные закладки.
- **#77** — локальное сравнение двух документов и ограниченный diff.

Это первая партия, не завершение списка из 100. Все остальные пункты остаются в очереди.

## Следующие группы

1. Экран и Windows (#51–60): одноразовый захват экрана, OCR, активное окно с согласием, браузерное расширение, QR, схемы.
2. Медиа (#61–70): локальное понимание изображений, аудио/видео, субтитры, таблицы; подключать тяжёлые модели только по желанию.
3. История и знания (#71–80): проекты, временная память, версии документов, проверка источников и мониторинг.
4. Продуктивность (#81–90): задачи, покупки, меню, бюджет, поездки, привычки, язык, контакты и недельное планирование.
5. Связь и сеть (#91–100): календари/почта, системный трей, quiet hours, откат, API, домашняя сеть и зашифрованная локальная синхронизация.

Перед выпуском каждой группы — компиляция, smoke-тесты, проверка отсутствия секретов/пользовательских баз в ZIP. Реальные Windows-устройства и пользовательские аккаунты потребуют проверки на ПК пользователя.

## Дизайн v6

Интерфейс обновляется в направлении «спокойный футуристичный операторский центр»: единая лента чата, читаемая типографика, компактная строка быстрых действий, заметный статус и согласованные тёмные элементы управления. Быстрые кнопки остаются опциональными; все навыки вызываются сообщением.
